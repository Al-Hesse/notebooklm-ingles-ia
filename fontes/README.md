# Fontes

Esta pasta contém a documentação das fontes utilizadas no NotebookLM para a criação do caderno temático sobre aprendizagem de inglês com apoio da Inteligência Artificial.

As fontes serão selecionadas buscando materiais confiáveis, gratuitos e relacionados a métodos de aprendizagem de idiomas.
