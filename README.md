# Aprendendo Inglês com Inteligência Artificial

### Contexto e Objetivos
Este repositório contém um Caderno Temático desenvolvido com o uso do NotebookLM. O objetivo principal é mapear e consolidar métodos de aprendizagem de inglês para adultos baseados em evidências científicas. 

O projeto explora o uso da Inteligência Artificial como ferramenta de curadoria, organização e testes ativos, resultando em um miniguia prático para estudantes.

### Estrutura do Repositório
- /fontes: Documentação dos materiais de referência utilizados.
- /prompts: Registro das perguntas estratégicas feitas à IA e seus resultados.
- /miniguia: Entrega final com resumos, glossário e prompts reutilizáveis.
