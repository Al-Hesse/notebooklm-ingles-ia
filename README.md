# Aprendendo Inglês com Inteligência Artificial

### Contexto e Objetivos
Este repositório contém um Caderno Temático desenvolvido com o uso do NotebookLM. O objetivo principal é explorar e consolidar o uso prático de ferramentas de Inteligência Artificial para facilitar o aprendizado de inglês.

O projeto utiliza a IA não apenas como tema de estudo, mas como ferramenta ativa de curadoria, conversação e organização, resultando em um miniguia de ferramentas e práticas para estudantes.

### Estrutura do Repositório
- /fontes: Documentação dos materiais de referência e ferramentas utilizados.
- /prompts: Registro das perguntas estratégicas feitas à IA e seus resultados.
- /miniguia: Entrega final com resumos, glossário e prompts reutilizáveis.
